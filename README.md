🌿 Gold Loan Management System

A MERN Stack web application to streamline the process of applying for gold loans, scheduling gold evaluations, and forwarding loan applications to banks.
This platform provides two portals:
User Portal for customers
Admin Portal for administrators

✨ Features

🧍‍♂️ User Portal

User Registration & Login (JWT-based authentication)
Book gold evaluation appointments
View appointment status & evaluation reports
Download evaluation reports
Apply for gold loans
Receive notifications (email updates)
View loan application status

🛠️ Admin Portal

Secure Admin Login
View all appointments
Cancel or reschedule appointments
View all gold loan applications
Forward loan applications to banks
Send reports to specific users via email

⚙️ Key Functionalities
✅ Authentication
Secure JWT-based login and signup for users and admins

✅ Appointments
Users can book appointments for gold evaluation
Admins can view, cancel, or reschedule appointments

✅ Loan Management
Users can apply for gold loans after evaluation
Admins can forward applications to the bank

✅ File Uploads
Evaluation reports are uploaded with Multer

✅ Notifications
Nodemailer sends emails about appointments and status updates
